1. Document Parsing & Entity Extraction

Module: resume_parser.py

Uploaded resumes are parsed directly from memory or disk using pypdf. The parser cleans artifact headers, normalizes Unicode whitespace, and runs targeted regular expressions and heuristic pattern matchers:

Email Extraction
r'[\w\.-]+@[\w\.-]+\.\w+'
Phone Extraction
r'(\+?\d{1,3}[-.\s]?)?\(?\d{3}\)?[-.\s]?\d{3}[-.\s]?\d{4}'
Experience Detection
r'(\d+(?:\.\d+)?)\s*\+?\s*(?:years?|yrs?)\b'
Education Parsing
Heuristic hierarchy: Ph.D. > Master's > Bachelor's > Associate

2. NLP Tokenization & Set Theory Skills Gap

Module: nlp_processor.py

The NLP engine standardizes the resume text by stripping punctuation, applying case normalization, and filtering out 150+ high-frequency English stopwords. Candidate competencies are cross-referenced with a comprehensive technical taxonomy spanning Programming, Web Frameworks, Cloud, Databases, and ML libraries.

Formal Set Theory Formulation:
Matched Skills \( S_{\text{matched}} = S_{\text{resume}} \cap S_{\text{job}} \)
Missing Skills \( S_{\text{missing}} = S_{\text{job}} \setminus S_{\text{resume}} \)
Bonus Skills \( S_{\text{bonus}} = S_{\text{resume}} \setminus S_{\text{job}} \)

3. Semantic TF-IDF & Cosine Similarity

Vector Space Model Representation

Beyond exact keyword matching, semantic contextual overlap is quantified using a Vector Space Model. We compute Term Frequency (TF) with sublinear logarithmic scaling and Inverse Document Frequency (IDF) over the candidate corpus:

// Cosine Similarity Equation
CosineSim(d_resume, d_job) = ( u • v ) / ( ||u||_2 * ||v||_2 )
// Sublinear TF Formulation
tf(t, d) = 1 + log(count(t, d)) if count(t, d) > 0 else 0

This captures holistic job context (e.g. distributed systems concepts, leadership terminology, agile workflow mentions) even when specific acronyms vary.

Multi-Factor Scoring Model

Final candidate scores are synthesized using a normalized 4-factor multi-criteria weighted equation:

Score = (0.50 × Skills) +
        (0.20 × Experience) +
        (0.20 × TF-IDF) +
        (0.10 × Education)
Skill Competencies 50% Weight
Relevant Experience 20% Weight
Semantic TF-IDF 20% Weight
Education Degree 10% Weight
